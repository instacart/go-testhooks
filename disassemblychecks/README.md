# Disassembly tests

To verify that building testhooks with "notest" build tag has the desired effect of stripping out test only code we run checks on the output of the disassembled code generated by go build.

The process is roughly as follows:
- build a sample binary with no build tags (default config)
- build a sample binary with "notest" build tag (notest config)
- generate the disassembled versions of both configs using -gcflags '-m -S'
- verify that the disassembled version of default config doesn't strip away the test codepaths
- verify that the disassembled version of notest config strips away the test codepaths

We follow the process above for each of the subdirectories within the disassemblychecks as we may want to verify more than one sample binary.

To run the checks, run `./run_checks.sh`

The checks build the sample binaries with `go build` and use a Python script to parse the
disassembled output.

To output the actual disassembled code and binaries for inspection, pass a directory argument to `run_checks.sh`, for example: `./run_checks.sh /tmp/out`. It will produce a folder structure like:
```
/tmp/out/errhook/go-build-bin-default.bin
/tmp/out/errhook/go-build-bin-notest.bin
/tmp/out/errhook/go-build-logs-default.txt
/tmp/out/errhook/go-build-logs-notest.txt
# ... other diassembly tests ...
```
